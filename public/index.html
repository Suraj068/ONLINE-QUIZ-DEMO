ABOUT THE PROJECT

Online Quiz System

This project is designed for BCA and BSc Computer Science students. It uses HTML, CSS and JavaScript for the frontend, Node.js + Express for the backend, and SQLite for persistent results.

📚 CS QuestionsProgramming, DBMS, DSA, OS, Networks and Web.
👀 Tab DetectionBrowser visibility changes are detected and recorded.
🗄️ DatabaseEvery submitted result is stored in SQLite.
🏆 LeaderboardHighest and lowest scores are shown automatically.
